## Real backend / v12 (supersedes mock account behavior in v11)

The modal now calls Express OTP/password/session endpoints. No arbitrary demo codes are accepted at runtime. The full standalone app runs frontend + API on one origin with `npm start`; deployment and domain instructions are in DEPLOY_VI.md. The managed dev entrypoint uses an isolated database and ephemeral local secret, with email unavailable unless explicitly configured.

Frontend synchronization preserves the legacy store, adds metadata for bookmark deletion/reset, includes AI choices and lesson state, and separates cached accounts. Delivery to real email and external hosting/DNS require owner configuration and have not been tested in this workspace.
